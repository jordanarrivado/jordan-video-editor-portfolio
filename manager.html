    Publish changes

    ⚡ One-click publish

    Commits your changes to GitHub. Vercel then updates the live site automatically (about a minute).

    • Saving to GitHub
    • Vercel is deploying
    • Live on your site

    One-time setup needed (about 3 minutes):

    1. Create a GitHub token: github.com → Fine-grained token. Repository access → Only select repositories → jordan-video-editor-portfolio. Permissions → Contents: Read and write. Generate and copy it.
    2. In Vercel: your project → Settings → Environment Variables, add GITHUB_TOKEN (the token) and ADMIN_PASSWORD (a password you choose).
    3. Vercel → Deployments → ⋯ on the latest → Redeploy. Then reopen this page.

    Manual publish (backup)
    1.  or 
    2. On GitHub, open projects.js → Edit, select all, paste, then Commit changes.
    3. Wait a minute or two, then press Mark as published.
